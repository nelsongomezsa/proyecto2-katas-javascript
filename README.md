# Katas de JavaScript

**56 ejercicios resueltos de JavaScript, de los fundamentos a la asincronía y el DOM.**

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?logo=javascript&logoColor=black)
![HTML](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)

> **English summary:** 56 solved JavaScript exercises covering the basics, ES6+ features, fetch requests and DOM manipulation. Plain JavaScript, no frameworks.

---

## Qué hay

| Carpeta | Ejercicios | Temas |
|---|---|---|
| [`ejercicios-basicos-avanzados/`](ejercicios-basicos-avanzados/) | 42 | Variables, condicionales, bucles, arrays, objetos y funciones |
| [`ejercicios-es6-asincronia/`](ejercicios-es6-asincronia/) | 9 | Sintaxis ES6+ (desestructuración, spread, funciones flecha) y peticiones con `fetch` y `.then()` |
| [`ejercicios-dom/`](ejercicios-dom/) | 5 | `querySelector`, creación de elementos y eventos |

## Cómo ejecutarlo

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/nelsongomezsa/proyecto2-katas-javascript.git && cd proyecto2-katas-javascript
   ```
2. **Ejercicios de consola** con Node.js:
   ```bash
   node ejercicios-basicos-avanzados/ejercicio-01.js
   ```
3. **Ejercicios con página HTML**: abre su `index.html` en el navegador.
